# 週4日ログイン・ミッション表示の更新

この変更は画面と学校用Apps Scriptの両方で動きます。学校の名簿、ポイント、所持カードを消す必要はありません。

1. 学校アカウントでGカード用スプレッドシートの **拡張機能 → Apps Script** を開きます。
2. `コード.gs` の全文を、このリポジトリの [`gas/Code.gs`](../gas/Code.gs) の全文に置き換え、保存します。`Bridge.html` は変更しません。
3. **デプロイ → デプロイを管理 → 現在のウェブアプリの編集（鉛筆） → バージョン「新しいバージョン」 → デプロイ** を選びます。`/exec` URLはそのままです。今回 `setup()` の再実行は不要です。
4. 公開ページを開き直します。ログインスタンプが月曜〜日曜の曜日で表示され、デイリーとウィークリーのミッションが分かれていることを確認します。

週4日ログインの100Gは、同じ月曜〜日曜の中で異なる4日目のログイン時に1回だけ付与されます。毎日の10Gも従来どおりです。ボーナスの金額は管理者メニューの「Gポイントと育成の数値」から変更できます。獲得履歴は `PointLog` の `login_weekly` 行に残ります。過去のログイン履歴も当週分は数えます。

ゲストは端末内の記録だけで同じ週4日ルールを使います。ゲストの初期ウィークリーミッションは「今週トレーニングを3回する」です。学校アカウントのミッションは、管理者メニューで既存の設定をそのまま編集できます。
