# ランキングの週間・月間・総合表示

学校アカウント側の Apps Script には `clasp` で [最新版の `gas/Code.gs`](../gas/Code.gs) を反映し、既存ウェブアプリをバージョン19へ再デプロイ済み。既存の `/exec` URLを使用する。`Bridge.html` と `Learning.gs` の内容は変更していない。`BattleLog` の既存記録を使用するため、シートの追加・`setup()` の再実行は不要。

[ランキング画面](https://ken-ui-web.github.io/g-card/#/ranking) を学校アカウントで開き、「週間」「月間」「総合」を切り替えて確認できる。

集計するのは、学校アカウント同士のオンライン対戦で確定した勝利です。CPU対戦・ゲスト対戦・管理者テスト対戦は含みません。各期間とも上位20名と自分の順位を表示し、メールアドレスは画面へ返しません。
