# 段階8：管理者画面の更新

今回、学校側で貼り替えるファイルは `gas/Code.gs` だけです。`gas/Learning.gs` と `gas/Bridge.html` は変更しません。既存のGカード用Apps Scriptプロジェクトとウェブアプリを使います。

1. [Code.gs の最新版](https://github.com/ken-ui-web/g-card/blob/main/gas/Code.gs)を開き、全文をコピーして、学校側Apps Scriptの `Code.gs` を貼り替えて保存します。
2. Apps Scriptの関数一覧から `setup` を選び、1回実行します。`AdminAdjustments`（Gポイント調整理由）と `AdminActions`（ニックネームのリセット履歴）のシートが追加されます。既存の名簿やポイントは消えません。
3. 「デプロイ」→「デプロイを管理」→既存ウェブアプリを編集→「新しいバージョン」で更新します。実行ユーザーとアクセス設定は現在の値を維持します。`/exec` URLは変わりません。
4. [Gカードの管理画面](https://ken-ui-web.github.io/g-card/#/admin)を開きます。古い画面が出る場合はSafariのタブを閉じて開き直します。

## 確認すること

- 「ダッシュボード」に今日のログイン・テスト受験・振り返り・Gポイント増減が表示される。
- 「生徒管理」で名簿と所持カード、最近のポイント履歴が見える。
- 先生の試験用アカウントで、理由を記入して少額を加算・減算し、`PointLog` と `AdminAdjustments` に1件ずつ記録される。二重送信でも同じ操作は一度だけ反映される。
- ニックネームをリセットすると次回ログイン時に再設定画面へ進み、`AdminActions` に履歴が残る。実施するアカウントを選んで確認する。
- 「カード・ミッション」でミッションの期間・条件・必要回数・報酬・有効状態を編集できる。
- 「CSV書き出し」で必要なシートを保存できる。テストの回答本文は記録していないため、`TestResponses` の `answersJson` 列は空欄です。`Questions` の書き出しには正解が含まれるため、保存先と共有先を確認してください。

ダッシュボードとCSVは管理者が画面を開いたときだけシートを読みます。生徒のホーム表示時にこの集計処理は走りません。
