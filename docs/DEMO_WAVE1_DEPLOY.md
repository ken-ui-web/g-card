# デモ用第1弾の学校側更新

フロントエンドは公開ページへ反映済み。学校用のApps Scriptは、先生の学校アカウントにある既存プロジェクトで以下を一度だけ更新する。

1. [gas/Code.gs](../gas/Code.gs) の全文を、Apps Scriptの `Code.gs` に貼り替えて保存する。`Bridge.html` と `Learning.gs` は今回変更しない。
2. 関数の一覧から `setup` を選んで実行する。既存の所持カード・Gポイント・先生が設定した価格は残したまま、Cardsの `trainingBonus` 列、新カード5枚、第1弾パック、`sellSSR` 設定を追加する。
3. `Cards` に10枚（従来5枚と新規5枚）、`Packs` に「第1弾パック」、`Settings` に `sellSSR` があることを確認する。`C014` レーザーカッターの `shopPrice` は空欄、効果は60ダメージ。
4. 「デプロイ」→「デプロイを管理」→既存ウェブアプリの編集→「新しいバージョン」→デプロイ。同じ `/exec` URLを使う。
5. [Gカードのホーム](https://ken-ui-web.github.io/g-card/#/home) を開き直し、ショップで新しいN/Rカードと「第1弾パック」を確認する。レーザーカッターはショップ単品では買えず、サンプルカードの対戦ではすぐに試せる。

第1弾パックは3枚200G、暫定の排出率はN 68.5%／R 30%／SSR 1.5%。まだSRカードがないため、第1弾だけSRを0%にする。先の弾を実装する際に見直す。
